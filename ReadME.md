# 📝 My Python Habit Tracker

This is a simple web app I built to track daily habits. I created this project to learn how to connect Python to a real database and how to build a user interface.

## 🛠️ What I Used
* **Python** - To write the core logic.
* **Streamlit** - To turn my Python script into an interactive web page.
* **SQLite** - To save my habits and completions so they don't disappear when I close the app.

## 🧠 What I Learned
* How to write basic SQL commands (like `INSERT` and `SELECT`) to manage data safely.
* How to split a project into different parts (a database file and a web app file).
* How to use virtual environments (`venv`) to keep my project organized.

## 🚀 How to Run It
If you want to try this out on your own computer, open your terminal and run these commands:

1. Install the required library:
   ```bash
   pip install streamlit
2. Run the application:
	```bash
	streamlit run app.py
